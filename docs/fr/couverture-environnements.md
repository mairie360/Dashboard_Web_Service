`npm test` exécute les tests Node avec un seul worker et leurs seuils de 60 %, conserve le LCOV natif, les captures V8 et les journaux dans `coverage/native`, puis remappe les sources TS/TSX originales avec c8. Les helpers Node gardent leurs seuils propres. Les composants sont mesurés par la suite React/V8 existante, avec les mêmes seuils.

La propriété des fichiers est déclarée dans `scripts/coverage-scope.cjs`, indépendamment des scores. La composition reprend chaque enregistrement V8 des fichiers attribués à React et conserve les enregistrements Node/c8 des autres sources. Elle vérifie le corpus complet, les empreintes avant/après, l’intégrité du LCOV Node canonique et le résultat des deux suites. Les entrées sont archivées sans modifier leurs compteurs dans `coverage/source-inputs`, avec provenance, avant publication de `coverage/lcov.info`. Une erreur d’intégrité bloque la publication ; un seuil non atteint reste un échec.
