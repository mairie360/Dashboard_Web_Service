`npm test` runs the Node tests with one worker and their 60% thresholds, preserves native LCOV, V8 captures and logs in `coverage/native`, then remaps the original TS/TSX sources with c8. Node helpers retain their own thresholds. Components are measured by the existing React/V8 suite with the same thresholds.

File ownership is declared in `scripts/coverage-scope.cjs`, independently of scores. Composition takes each V8 record owned by React and preserves the Node/c8 records for other sources. It verifies the complete inventory, source hashes before and after collection, canonical Node LCOV integrity and both suite results. Inputs are archived without changing their counters in `coverage/source-inputs`, with provenance, before publishing `coverage/lcov.info`. An integrity error blocks publication; insufficient coverage remains a failure.
